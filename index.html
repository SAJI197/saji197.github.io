BAB AL FALAH Backups

A private backup utility used only by BAB AL FALAH for its own records.

BAB AL FALAH Backups keeps an off-site copy of BAB AL FALAH's own accounting system backups in BAB AL FALAH's own Google Drive. It is an internal tool. It is not offered to the public and has no other users.

What it does

  • Each backup is encrypted on BAB AL FALAH's own computer with AES-256-GCM before anything is uploaded. Google Drive only ever receives encrypted files.
  • The encryption key never leaves BAB AL FALAH's computer and its offline recovery copy.
  • The app uses only the Google Drive permission https://www.googleapis.com/auth/drive.file, which lets it see and manage only the files it creates itself. It cannot see any other file in the Drive.
  • After each upload it checks the copy in Google Drive against the original and it never deletes or replaces a backup.
